# @Stripchat_traffic_bot — новый WebApp: ТЗ

Бот: https://t.me/Stripchat_traffic_bot
Макеты (кликабельные): https://claude.ai/artifact/4MiSxe3j8hZHmpCo3UoA9P — утверждён **тёмный красный** ряд (экраны 0–5 + 3b). Варианты A–D во втором ряду — отклонённые стили, их не делаем.
Рабочая вёрстка: папка `webapp/` (чистый HTML/CSS/JS, без сборки). Открывается в обычном браузере на моковых данных — см. «Как запустить».

## 1. Что меняется относительно текущего WebApp

| Было | Стало |
|---|---|
| Кнопки навигации разные на каждом экране | Нижнее меню из 5 вкладок: **Заказ · Заказы · Баланс · Полезное · Партнёрка** |
| Отдельная страница «Профиль» (дата + баланс) | Удалена. Баланс — в шапке экрана заказа и на вкладке «Баланс» |
| Старт выбирается в `<select>` с красными/зелёными пунктами, длительность — отдельным полем ввода | Сетка 24 часа + степпер длительности. Выбранный диапазон подсвечивается, конфликт с занятым часом видно сразу |
| Цена и остаток не видны до отправки | Внизу всегда: «3 ч × $10 · Остаток $169.63» и кнопка «Заказать за $30» |
| Таблица заказов, статусы на 2 языках, опечатка «Отмнено.» | Карточки, вкладки «Предстоящие / История», статусы на русском |
| Длинная инструкция под формой | Экран первого запуска (3 шага) + ссылка на teletype |
| Пополнение: поле суммы + жёлтая плашка | Быстрые суммы, тарифы, подсказка «добавьте $X — час дешевле», история операций |

## 2. Экраны

### 0 · Первый запуск (`onboarding`)
Показывается один раз: когда у пользователя нет флага `onboarded` (локально `localStorage.onboarded` или поле в `/api/me`). Три шага, ссылка на инструкцию `https://teletype.in/@webcamtraffic/stripchat-traffic-bot` (через `Telegram.WebApp.openLink`). Кнопки: «Создать первый заказ», «Сначала пополнить баланс». Можно открыть повторно по ссылке «Как это работает» на экране заказа.

### 1 · Новый заказ (`order`) — главный
- **Модель:** поле `stripchat.com/ [ник]`. Если вставили полную ссылку — обрезаем до ника. Под полем — чипы **«Недавние»** (последние 5 ников из заказов пользователя).
- **Дата:** 7 дней вперёд, первая — «Сег».
- **Время старта:** сетка 00–23 в часовом поясе пользователя. Состояния ячейки:
  - `free` — свободно, можно выбрать;
  - `busy` — занято (штриховка + зачёркнуто), нельзя выбрать;
  - `past` — прошло или старт раньше чем через 15 минут, нельзя выбрать;
  - выбранный диапазон — красный (`--accent`); если диапазон задевает `busy` — ячейка «конфликт» (красная рамка) и ошибка под сеткой.
- **Длительность:** степпер 1–12 ч.
- При смене дня старт сам ставится на первое окно, куда влезает выбранная длительность.
- **Сообщение под формой:** либо ошибка (занято / после 24:00 / нет ника / не хватает денег), либо подсказка «Модель должна быть онлайн с HH:45 — за 15 минут до старта».
- **Низ экрана (фиксированный):** «N ч × $цена», «Остаток $X», кнопка:
  - «Заказать за $N» — всё ок;
  - «Пополнить баланс» — не хватает денег (ведёт на «Баланс»);
  - неактивная «Выберите свободное время» — есть ошибка.

### 2 · Заказ принят (`confirm`)
После успешного `POST /orders`. Детали заказа, списано, остаток. **Переключатель «Напомнить в Telegram»** (по умолчанию включён) → `PATCH /orders/:id {remind}`. Кнопки: «Мои заказы», «Ещё один заказ». Показывается системная `BackButton` Telegram.

### 3 · Мои заказы (`orders`) и 3b · История
Вкладки **Предстоящие** (`scheduled`, `running`) и **История** (`done`, `cancelled`).
- `running` — «Идёт», прогресс-бар, «Осталось N».
- `scheduled` — «Запланирован», «Старт через N · онлайн с HH:MM · напомним», кнопки **«Отменить»** (подтверждение через `Telegram.WebApp.showConfirm`, деньги возвращаются на баланс) и **«Повторить»**.
- `done` / `cancelled` — компактная карточка + **«Повторить»**. Для отменённых: «$N возвращено».
- **«Повторить»** = открыть экран заказа с тем же ником и той же длительностью, день — сегодня, старт — первое свободное окно. Отдельный эндпоинт не нужен.

### 4 · Баланс (`wallet`)
- Доступно $X и «≈ N ч по вашему тарифу $P/ч».
- Тарифы: до $50 — $10/ч · от $50 — $9/ч · от $200 — $8/ч. Подсвечен тариф для введённой суммы.
- Сумма: поле + быстрые $20 / $50 / $100 / $200, рядом «≈ N ч по $P».
- Подсказка-апселл: < $50 → «Добавьте $X — и час будет стоить $9»; $50–199 → «От $200 час стоит $8». Нажатие ставит сумму.
- Кнопка «Оплатить $N криптой (BTC · ETH · USDT)» → `POST /topup` → открыть `pay_url` (trybit) через `openLink`.
- Список операций: пополнения, списания за заказы, возвраты, реф-начисления.

### 5 · Полезное (`tools`)
Список из 4 ссылок на бесплатные виджеты и гайды ewohub.com (массив `TOOLS` в `app.js`), открываются через `Telegram.WebApp.openLink`. UTM `?utm_source=stripchat_traffic_bot&utm_medium=webapp` стоит перед якорем.
- Лучшие часы для стрима на Stripchat — `/ru/best-hours-to-stream-chaturbate#sc-hours`
- Топ-20 тегов прямо сейчас на Stripchat — `/ru/best-hours-to-stream-chaturbate#sc-tags`
- Твои первые 14 дней на Stripchat — `/ru/stripchat-first-14-days-guide`
- Цены Fan Club на Stripchat — `/ru/stripchat-fan-club-pricing-guide`

Бэкенд не нужен.

### 6 · Партнёрка (`referral`)
- Текст «получайте X% с каждого пополнения приглашённых».
- Счётчики: приглашено, заработано.
- Ссылка `https://t.me/Stripchat_traffic_bot?start=ref_<code>` + «Копировать» + «Поделиться в Telegram» (`openTelegramLink('https://t.me/share/url?url=…')`).
- Список приглашённых с суммой начислений, пустое состояние «Пока никого».

## 3. Новые функции (нужна доработка бэкенда)

### 3.1 Напоминание в Telegram за 30 минут
- Поле `orders.remind boolean default true`.
- Планировщик (cron раз в минуту): заказы `status='scheduled' AND remind AND reminded_at IS NULL AND start_utc - now() <= 30 min` → сообщение от бота, затем `reminded_at = now()`.
- Текст: «⏰ Через 30 минут старт продвижения *{model}* ({HH:MM}–{HH:MM}). Будьте онлайн с {HH:MM}.» + inline-кнопка «Открыть заказы» (`web_app` на WebApp).
- По желанию: сообщения «Продвижение началось» и «Завершено».

### 3.2 «Повторить заказ»
Только фронт (см. экран 3). Бэкенд не меняется.

### 3.3 «Недавние ники»
`GET /me` возвращает `recent_models`: последние 5 уникальных ников из заказов пользователя, свежие первыми. Отдельная таблица не нужна, достаточно `SELECT model … GROUP BY model ORDER BY max(created_at) DESC LIMIT 5`.

### 3.4 Партнёрка
- `users.ref_code` (уникальный, генерируется при регистрации), `users.referrer_id` (nullable).
- Бот, `/start ref_<code>`: если пользователь **новый** и код не свой → записать `referrer_id`. Существующим не перезаписывать.
- При зачислении пополнения (webhook trybit) — если есть `referrer_id`, начислить рефереру `amount × REF_PERCENT` на баланс + запись в `transactions` с `type='referral'`.
- `REF_PERCENT` — задать в конфиге. **[Владелец: какой процент?]**

## 4. API

Все запросы с заголовком `X-Telegram-Init-Data: <Telegram.WebApp.initData>`. Сервер **обязан** проверять подпись initData (HMAC-SHA256 с ключом от токена бота, см. документацию Telegram «Validating data received via the Mini App») и брать `user.id` только оттуда.
Время на сервере — UTC. Клиент передаёт свой часовой пояс (`tz`, IANA, напр. `Europe/Kyiv`) для сетки слотов, а время старта заказа — уже в ISO UTC.

| Метод | Путь | Тело / параметры | Ответ |
|---|---|---|---|
| GET | `/api/me` | — | `{user_id, first_seen, balance, price_per_hour, recent_models[], onboarded}` |
| GET | `/api/slots` | `?date=YYYY-MM-DD&tz=Europe/Kyiv` | `{date, tz, hours:[{hour:0..23, status:'free'\|'busy'\|'past'}]}` |
| POST | `/api/orders` | `{model, start (ISO UTC), hours, remind}` | `{order, balance}` · `409` слот занят · `402` мало денег · `422` невалидный ник/время |
| GET | `/api/orders` | `?scope=upcoming\|history` | `{orders:[{id, model, start, hours, cost, status, remind, refunded?}]}` |
| POST | `/api/orders/:id/cancel` | — | `{order, balance}` · только для `scheduled` и до старта |
| PATCH | `/api/orders/:id` | `{remind}` | `{order}` |
| GET | `/api/wallet/transactions` | — | `{transactions:[{id, type:'topup'\|'order'\|'refund'\|'referral', title, amount, at}]}` |
| POST | `/api/topup` | `{amount}` | `{pay_url}` (инвойс trybit) |
| GET | `/api/referral` | — | `{link, percent, invited, earned, referrals:[{name, earned}]}` |
| POST | `/api/webhooks/trybit` | от trybit | зачислить баланс, обновить тариф, реф-начисление |

Ошибки: JSON `{code, message}`; `message` показывается пользователю как есть, поэтому на русском.

**Проверки на сервере при создании заказа** (клиенту не доверяем):
1. Старт ≥ now + 15 минут.
2. Все часы диапазона свободны (транзакция / блокировка, чтобы два пользователя не заняли один час) → иначе `409`.
3. `hours` от 1 до 12. **[Владелец: можно ли переходить через полночь?** Сейчас фронт не даёт заказу закончиться позже 24:00.]
4. Баланс ≥ `hours × price_per_hour` → иначе `402`. Списание и создание заказа — в одной транзакции.

**Тариф `price_per_hour`** — сохраняем текущую логику бэкенда ($10 / $9 от $50 / $8 от $200). **[Владелец: тариф считается от одного пополнения или от суммы всех?]** Шкала дублируется во фронте в `TIERS` (`webapp/app.js`) — держать одинаковой.

## 5. Дизайн

Тёмная тема, красный акцент. Все цвета — CSS-переменные в начале `webapp/styles.css`.

| Токен | Цвет | Где |
|---|---|---|
| `--bg` | `#141414` | фон |
| `--surface` / `--surface-2` | `#212121` / `#2B2B2B` | карточки, поля / кнопки второго плана, свободные часы |
| `--border` | `#363636` | рамки |
| `--text` / `--muted` | `#FFFFFF` / `#A8A8A8` | текст / подписи |
| `--accent` | `#A2262E` | главные кнопки, выбранные часы, активный тариф (текст на нём белый) |
| `--accent-text` | `#FF5A62` | ссылки, активная вкладка меню |
| `--info` | `#5B9BFF` | статус «Запланирован», подсказки |
| `--err-text` | `#FFB4B4` | ошибки, «Отменён» |

Шрифт Manrope (Google Fonts), 400–800, цифры `tabular-nums`. Кнопки высотой ≥ 44 px. Ширина контента до 520 px.
Telegram: `ready()`, `expand()`, цвета шапки и фона `#141414`, `BackButton` на экране подтверждения, `HapticFeedback` на выборе, `showConfirm` для отмены, `openLink` для оплаты и инструкции.

## 6. Как запустить вёрстку

```
cd webapp
npx serve -p 4410 .
```
Открыть http://localhost:4410 — вне Telegram (нет `initData`) вёрстка сама работает на моковых данных из `api.js`. Внутри Telegram ходит в настоящий API: `/api/...` относительно домена WebApp (константа `API_BASE` в `api.js`).

Файлы:
- `index.html` — оболочка, подключает Telegram SDK.
- `styles.css` — все стили и токены.
- `api.js` — реальные запросы + мок (`mockApi`), переключение автоматическое.
- `app.js` — экраны, логика выбора слота, события.
